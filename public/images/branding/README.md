# Branding Assets

Place your mascot/branding images in this directory.

## Expected files:

- **favicon.ico** — Browser tab icon (32x32 or 64x64)
- **logo-dark.png** — Dashboard header logo (48x48 or 64x64, transparent background)
- **mascot-full.png** — Full mascot illustration for empty states or sidebar (256x256+, transparent)
- **mascot-small.png** — Small mascot for loading spinner or sidebar accent (128x128, transparent)
- **mascot-error.png** — Error state mascot variant (256x256+, transparent)

## Format recommendations:

- **PNG** with transparency for best results
- **Optimize** images with TinyPNG or similar before adding
- **Blue/yellow color scheme** to match the example character

Once images are added, they will automatically integrate into the dashboard.
